# Full Circle Leadership Advisors — draft website preview

A static preview of the draft website for *Full Circle Leadership* by Michele and Tim Breene, shared for review.

View it at **https://ek300993.github.io/full-circle-leadership-draft/**

- This is a work-in-progress draft, not the live site. Lorem ipsum and initials stand in for text and photos still to be supplied; links marked `#` (ordering, privacy policy) are not set up yet.
- The pages ask search engines not to index them.
- Earlier drafts stay available: the label in the bottom-left corner says which draft you're viewing and opens a menu to switch to the same page in another one. Earlier drafts live in `draft-1/`, `draft-2/` and so on.
- The site itself is built as a WordPress theme; these files are an export of it, refreshed with `update-preview.sh` in the project.
